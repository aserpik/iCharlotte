Objection Rules

ALWAYS include "vague, ambiguous, overbroad" objections

Mandatory rule: if selected, this objection is included for every request, regardless of the request wording.

Inserted objection: Responding Party objects to this Request on the grounds that it calls for speculation and is vague, ambiguous, uncertain and overbroad.

Include ambiguous term objection when the discovery request contains word(s) that are confusing or not obviously clear

Conditional rule: include only when the request contains a confusing, undefined, or not-obviously-clear term. The agent identifies the term and inserts it into the objection text.

Include relevance and privacy objections when Discovery asks for information not related to the case

Conditional rule: include when the request seeks information that appears unrelated to the case or invades privacy.

Include burdensome objections when the discovery asks for a lot of information

Conditional rule: include when the request asks for a large volume of information, lacks reasonable limits, or would impose undue burden or expense.

Include privilege objections when the discovery asks for potentially privileged information

Conditional rule: include when the request could seek attorney-client communications, work product, investigation strategy, or other protected information.

Include Expert Opinion or Legal Conclusion objections when Request calls for potential legal conclusion or expert opinion

Conditional rule: include when the request calls for expert analysis, legal opinion, or legal characterization.

Substantive Response Rules

Answer only the question being asked using as few words as possible.

Instruction rule: apply to every drafted substantive answer for Special Interrogatories and FI custom mode.
