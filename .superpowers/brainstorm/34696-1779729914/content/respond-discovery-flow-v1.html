Respond to Discovery Wizard Flow

Proposed guided flow while keeping the existing Discovery -> Respond subtab intact.

End-to-end task flow
Step 1

Select Task

Wizard card: Respond to Discovery

Step 2

Select File

Pick one incoming discovery PDF

Step 3

Detect Type + Parse

Filename, then first-page text, then parser

Step 4

Rules

Selectable objection and response rules while parsing runs

Step 5

Context

Select case files for answer drafting

Step 6

Generate Proposals

Selected rules + parsed requests + context produce objection and substantive text per request.

Step 7

Review One by One

User edits objections and answers, toggles standard objections, and approves each request.

Step 8

Assemble Word Output

Existing caption/template, preliminary statement, waiver, reservation, and verification logic.

Key design choices already locked

  • Existing Discovery -> Respond subtab remains available.
  • Discovery type detection uses filename first, first-page text second, and asks only if unclear or conflicting.
  • RFA/RPD show objection rules only; hidden substantive defaults still apply.
  • Custom rules go into a shared library, with wizard UI first.
  • Every request must be explicitly approved before final assembly.
