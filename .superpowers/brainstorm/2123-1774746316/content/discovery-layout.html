Key Layout Decisions

  • QSplitter divides left/right panes (resizable)
  • Left pane scrolls independently if content overflows
  • "Standard Type" dropdown hides when mode is Custom or Additional
  • "Instructions" box is optional for Standard mode, required for Custom/Additional
  • Party roster edits sync back to case variables (plaintiffs/defendants)
  • Document box reuses ChatTab's drag-and-drop pattern
  • Status bar in right pane shows request count, set number, and target party
